CAD 知识助手 · 插件详情

集成在 SolidWorks / Siemens NX 中的 AI 智能问答插件，连接后台知识库管理系统

01简介

一款集成在 SolidWorks / Siemens NX 环境中的 AI 智能问答插件。能够连接后台知识库管理系统，提供知识问答功能，帮助设计工程师快速查询设计规范、材料特性、标准件参数等专业知识，提高设计效率。

02使用说明

在使用 CAD 知识助手前，请仔细阅读以下说明：

  1. 本插件集成于 SolidWorks / Siemens NX 环境中，基于接入的知识库内容提供智能问答服务，支持快速查询设计规范、材料特性、标准件参数等专业知识，服务范围以实际入库内容为准。
  2. 所有回答内容均取自授权知识库，不进行无依据自由生成；每条回答均关联对应知识出处，可随时查阅原始内容核验信息准确性。
  3. 您可使用自然语言直接提问，提问越精准、限定范围越清晰，回答的匹配度与准确性越高；若未检索到匹配内容，系统将明确告知无结果。
  4. 系统将按账号权限匹配对应知识范围，请您遵守企业信息安全管理规定，规范使用与传播相关知识内容。
  5. 在安装前，请确保您的计算机满足以下运行环境：
环境 所需版本
操作系统 Windows 10 / Windows 11
SolidWorks / Siemens NX SolidWorks 2020 及以上（64 位）/ Siemens NX 2506 及以上（64 位）
.NET Framework 4.7.2 或更高版本
WebView2 Microsoft Edge WebView2 Runtime（最新版）
网络 需要网络连接，支持访问企业局域网及互联网服务
  1. 配置服务域名为：10.89.33.80:17000，账号及密码与 AI 知识助手账号密码相同。
